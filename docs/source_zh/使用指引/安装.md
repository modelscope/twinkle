# Twinkle安装

| 你要做的事 | 安装方式 |
| --- | --- |
| 在本地 GPU 上训练、推理 | `pip install twinkle-kit` |
| 用 Python SDK 连接远程服务 | 见下方源码安装 |
| 自己部署 HTTP 服务 | 见下方源码安装 |

## 源代码安装

```shell
git clone https://github.com/modelscope/twinkle.git
cd twinkle
pip install -e .                                                        # 本地训练和推理
pip install -e . -e ./twinkle_cs/client                                 # Python SDK，提供 twinkle-auto
pip install -e . -e ./twinkle_cs/server                                 # HTTP 服务端，提供 twinkle-server
pip install -e '.[test]' -e ./twinkle_cs/client -e ./twinkle_cs/server  # 同时开发三个包
```

使用 Swift 的模板或模型加载器时，另外安装匹配版本的 `ms-swift`。



## Docker 镜像

你也可以使用我们的预构建 Docker 镜像：

```text
modelscope-registry.cn-hangzhou.cr.aliyuncs.com/modelscope-repo/modelscope:twinkle-1.0.0.dev
```

## 客户端安装

如果你需要使用 Twinkle 的 Client 进行远程训练，可以使用我们的一键安装脚本：

```shell
# Mac or Linux
sh INSTALL_CLIENT.sh
# Windows, Open with PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\INSTALL_CLIENT.ps1
```

这个脚本会下载或利用 conda，创建一个叫 `twinkle-client` 的虚拟环境，这个环境可以直接用于远端训练。

## Megatron 依赖安装

如果你需要安装 Megatron 相关依赖，可以使用如下脚本：

```shell
sh INSTALL_MEGATRON.sh
```

## 支持的硬件

| 硬件环境                     | 备注                          |
|--------------------------|-----------------------------|
| GPU A10/A100/H100/RTX系列等 |                             |
| GPU T4/V100等             | 不支持bfloat16、Flash-Attention |
| Ascend NPU               | 部分算子不支持                     |
| 昆仑芯 XPU (P800)         | 经 cuda-alike 路线支持; 部分算子仅 fp16, 详见 [XPU 的支持](XPU的支持.md) |
| PPU                      | 支持                          |
| CPU                      | 支持dataset、dataloader等部分组件   |
