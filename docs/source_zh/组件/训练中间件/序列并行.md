# 序列并行 (SP)

序列并行沿序列维度将长序列分割到多个 GPU 上，使训练能处理超出单卡显存的序列长度。Twinkle 实现了 Ulysses 风格的序列并行，并可选地支持派生环形注意力。

## 概览

| 概念 | 说明 |
|------|------|
| **SequenceParallelConfig** | SP 配置数据类 |
| **SequenceParallelStrategy** | 封装 SP 生命周期的策略类 |
| **SequenceParallel** | 核心实现，处理填充/分割/聚合 |

## 配置

```python
from twinkle.model.transformers.strategy.sequence_parallel import SequenceParallelConfig

config = SequenceParallelConfig(
    enabled=True,           # 启用序列并行
    ulysses_size=None,      # Ulysses SP 并行度（若为 None 则从 DeviceMesh 自动推导）
)
```

## 配合 DeviceMesh 使用

在 `DeviceMesh.from_sizes()` 中设置 `ulysses_size` 即可激活 SP：

```python
from twinkle.utils import DeviceMesh

# 8 卡：4 路 Ulysses SP × 2 路数据并行
device_mesh = DeviceMesh.from_sizes(
    world_size=8,
    dp_size=2,
    ulysses_size=4,
)
```

## 工作原理

1. **填充** — 输入序列被填充到可被 SP 并行度整除的长度
2. **分割** — 填充后的输入沿序列维度均匀分配到各 SP rank
3. **分布式注意力** — SDPA 和 FlashAttention 2/3 被 patch 为在注意力计算前后执行 Ulysses all-to-all 通信
4. **聚合** — 收集实际存在的 logps、entropies、values 及请求的 logits，再交给原有完整序列 loss

## 支持的注意力后端

| 后端 | 状态 |
|------|------|
| FlashAttention 2 / 3 | 支持 Ulysses 和 packed/padding-free 路径，需要兼容的 kernel |
| SDPA | 支持（仅非打包批次）|
| 派生环形注意力 | 需要 CUDA FlashAttention 2/3；不兼容平台在初始化时明确报错 |

## Qwen3.5 线性注意力

SP 自动检测 Qwen3.5 GatedDeltaNet 线性注意力层，并应用 `Qwen3_5GatedDeltaNetUlyssesPatch`，确保混合注意力架构下序列并行的正确性。

## MoE 辅助损失

对于 MoE 模型，SP 自动安装前向 hook，在计算辅助损失前跨 SP rank 聚合路由 logits，确保负载均衡信号的正确性。

## 关键约束

- `num_key_value_heads` 必须能被 `ulysses_size` 整除（Ulysses 模式），否则回退到环形注意力
- 打包/padding-free 批次需要 FlashAttention 2 或 3
- 派生环形注意力要求 `batch_size == 1`（打包格式）
- `torch.distributed` 必须已初始化

## 每模型上下文与 Processor 回调

每个 strategy 持有自己的上下文。`prepare_model_inputs` 一次处理固定的模型/loss 序列字段；多模态文本在视觉特征合并后才切分。模型 forward 位于 `with sp.context()` 内，checkpoint 重算也恢复对应 batch 的上下文。视觉模块显式登记为本地计算；文本模块漏注册时直接报错。

任务池化和 unpacking 保留在 `InputProcessor.postprocess_outputs`。模型只注入 `gather_fn(inputs, outputs)` 和可反传的 `reduce_fn(tensor, op)` 两个普通函数。池化通过 batch-local `_sequence_layout` 中的位置/索引张量对齐局部特征；这些元数据不传给 HF 模型。Processor 不接收或导入具体 SP strategy，非 SP 路径不需要回调。即使没有 logps 或 labels，values 也会 gather；单 token values 保留 `[B, 1]` 序列轴。不支持 KV-cache decode。

不增加 loss 字段声明，不改变 loss 数学。Ring 保持逐段 padding 和 zigzag 顺序，显式拒绝左 padding。Qwen3.5 GDN 从所属上下文获取全局 padding mask 后再切本 rank，避免新版 Transformers 将 recurrent mask 截为尾部时错用其他分片的 mask。
